# Инициатива Астры

Плагин для Astra, который даёт Астре инициативу: она сама начинает разговор, а не только отвечает.

## Как это работает

Плагин сам ничего не пишет и не озвучивает. Когда наступает подходящий момент, он отправляет в свой тред
короткую служебную подсказку через `send_chat_message`, а отвечает на неё **сама Астра**: её моделью,
её персонажем и (если включено «Озвучивать») её голосом.

Что стоит знать:

- Подсказка видна в треде плагина как сообщение от плагина, а не от вас. Ответ Астры идёт следом.
- Каждая инициатива — один запрос к модели, поэтому есть жёсткие лимиты (ниже).
- Плагин не видит, двигаете ли вы мышью. «Вы за компьютером» он определяет по косвенным признакам:
  экран разблокирован, вы говорили или писали Астре. Если оставить разблокированный компьютер без присмотра,
  сценарий «Долгое молчание» всё равно может сработать.

## Сценарии

Каждый включается и выключается в настройках.

1. **Утреннее приветствие.** Первая активность за день (разблокировка экрана, голос, сообщение) в промежутке
   между «Утро начинается с» и «Здороваться не позже». Астра здоровается и спрашивает про планы. Раз в день.
2. **Полуночник.** Вы активны в окне из 7 часов, начиная с «Ночь начинается с» (по умолчанию 01:00–08:00).
   Астра мягко предлагает закругляться. Раз за ночь. Тихие часы сильнее этого сценария: с настройками по умолчанию
   он может сработать только между 01:00 и 03:00.
3. **Долгое молчание.** Экран не заблокирован, но вы не общались с Астрой дольше порога (по умолчанию 3 часа).
   Отсчёт идёт от последнего разговора, разблокировки, запуска плагина или прошлой инициативы.
4. **Возврат к теме.** Астра спрашивает, чем закончилось то, что обсуждали вчера. Идёт в одном сообщении с
   утренним приветствием, а если приветствие выключено, отправляется само, но только когда есть что вспомнить.
   Заметки о темах плагин берёт из ваших фраз (голос и чат, только если ≥ 20 символов) и из инструмента
   `remember_topic`, который Астра вызывает сама. Хранятся последние 150 заметок за 60 дней в `data/topics.json`
   внутри папки плагина, больше нигде. Старые заметки также подмешиваются в «Долгое молчание» и «Случайную мысль»
   (не чаще раза в неделю на заметку).
5. **Случайная мысль.** По умолчанию включена. В выбранные дни (шанс задаётся в настройках) в случайное время
   с 9 до 22 часов Астра делится мыслью или вопросом.

## Когда плагин молчит

Плагин не начинает разговор, если:

- прошёл дневной лимит (по умолчанию 4) или не истёк минимальный интервал между инициативами (по умолчанию 1,5 часа);
- сейчас тихие часы (по умолчанию 03:00–08:00);
- экран заблокирован;
- Астра слушает, обрабатывает запрос или говорит (`state_changed`, `tts_started`, `tts_completed`);
- с последней реплики в чате прошло меньше «Паузы после разговора» (по умолчанию 3 минуты);
- вы попросили помолчать;
- прошлая попытка не удалась (тогда повтор не раньше чем через 10 минут, а неудачная попытка в счёт лимита не идёт).

Счётчик лимита растёт, как только демон принял сообщение.

## Инструменты для ассистента

- `pause_initiative(duration)`: «не пиши мне до вечера», «помолчи час». Принимает `30m`, `1h`, `1h30m`, `90` (минуты),
  `until_evening`, `until_tomorrow`.
- `resume_initiative()`: снять паузу.
- `initiative_status()`: что включено, сколько инициатив осталось на сегодня, есть ли пауза.
- `remember_topic(topic)`: заметка для сценария «Возврат к теме».

## Настройки

Все настройки в Settings → Plugins → Инициатива Астры.

| Настройка | По умолчанию |
|---|---|
| Утреннее приветствие, «Утро начинается с», «Здороваться не позже» | вкл, 8, 12 |
| Возврат к теме | вкл |
| Полуночник, «Ночь начинается с» | вкл, 1 |
| Долгое молчание, порог в часах | вкл, 3 |
| Случайная мысль, шанс в день | вкл, 40% |
| Инициатив в день, не больше | 4 |
| Минимум между инициативами | 90 мин |
| Тихие часы | вкл, 03:00–08:00 |
| Пауза после разговора | 3 мин |
| Озвучивать | вкл |
| Характер | пусто |
| Пробный режим | выкл |

**Характер** — свободный текст, который добавляется в подсказку: «Говори коротко и с лёгкой иронией, не
дави вопросами».

**Пробный режим** ничего не отправляет модели, а записывает в журнал, что было бы сказано. Включите его на
первый день, чтобы увидеть, когда плагин срабатывает, не тратя баланс. Такие «инициативы» засчитываются в
дневной лимит.

## Разрешения

- `subscribe_events` (`state_changed`, `lock_state_changed`, `speech_recognized`, `chat_message`, `tts_started`,
  `tts_completed`, `tts_interrupted`): понять, что вы за компьютером и что идёт разговор. Транскрипты речи плагин
  не передаёт никуда, кроме коротких заметок о темах в своей папке.
- `send_chat_message`: попросить Астру начать разговор. Это высокорисковое разрешение, у него отдельная галочка.
  Из файла `.astraplugin` оно не принимается, плагин нужно загружать из папки.

## Подключение

1. В Astra откройте **Settings → Privacy** и включите **«Allow unsigned plugins»**.
2. Откройте **Plugins → Dev**, вставьте путь к папке плагина в поле **«Load a plugin»** и нажмите кнопку загрузки.
3. Плагин запускается сразу. После перезапуска Astra плагин, загруженный из папки, возвращается **выключенным**
   (так задумано): включите его снова на вкладке Installed.
4. Если загрузка не удалась, сообщение назовёт причину, а на карточке плагина будет конец его журнала.

## Установка из GitHub

```bash
git clone <адрес-репозитория> first-word
```

Затем загрузите папку `first-word` в Astra по шагам выше. Из файла `.astraplugin` плагин поставить нельзя:
Astra не принимает для импортированных файлов разрешение `send_chat_message`.

## Разработка

Нужен `astra-plugin` (см. репозиторий AstraPlugins) и Python 3.10+.

```bash
astra-plugin check . --strict
astra-plugin test .
astra-plugin logs first-word
```
